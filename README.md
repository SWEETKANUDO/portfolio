## 🌟 About the Project

Welcome to my personal portfolio!

This website is designed to introduce me as a developer and present my technical skills, projects, and learning journey in one place.

Built with **HTML5 and CSS3**, the portfolio focuses on a clean layout, organized content, and a user-friendly browsing experience.

## ✨ Features

- 👨‍💻 Personal introduction and profile.
- 🛠️ Technical skills showcase.
- 📂 Projects and work samples.
- 🎓 Education details.
- 📱 Responsive layout for different screen sizes.
- 🎨 Custom styling using CSS3.

## 🚀 Run Locally

Want to run the portfolio on your computer? Follow these steps.

### 1. Clone the Repository

```bash
git clone https://github.com/SWEETKANUDO/portfolio.git
```

### 2. Open the Project Folder

```bash
cd portfolio
```

### 3. Run the Website

Open the `index.html` file in your browser.

You can also use the Live Server extension in Visual Studio Code for local development.

**No framework or package installation is required** for a basic HTML and CSS portfolio.
